# Lister v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the v1 Lister outliner: a `core` library for the `.lister` format, a Fastify server with file watching and merge, a `lister` CLI usable by agents, a React web outliner with Admin, and an installable agent Skill.

**Architecture:** pnpm monorepo. `core` is pure functions over text and the `Bullet`/`OutlineFile` model and is the single source of truth for the format. `server` holds an in-memory model per loaded Outline File, persists with debounced whole-file writes, watches for external edits and three-way merges by Bullet id, and exposes REST + WebSocket. `cli` uses `core` directly for reads and prefers the server API for writes. `web` is a Vite React client served by the server.

**Tech Stack:** Node 22, TypeScript 5, pnpm 10, Fastify 5 + @fastify/websocket + @fastify/static, chokidar 4, commander 12, React 18, Vite 6, zustand, @dnd-kit/core, `node --test` with `tsx`.

**Spec:** `docs/superpowers/specs/2026-09-19-lister-design.md`

## Global Constraints

- Node `>=22`. ESM everywhere (`"type": "module"`).
- Outline File extension is exactly `.lister`. Line syntax `- ` with 2-space indent. Header line `# Name [id:..] [parent:..]`.
- Bullet IDs: 8 chars from `[0-9a-z]`.
- Server binds `127.0.0.1` only. Default port 7433.
- Never write to a project's `.gitignore`. Exclusion goes through global git excludes and `.git/info/exclude`.
- Metadata Annotation order on serialise: `id`, `folder`, `date`, `priority`, `done`, appended after text.
- Vocabulary per `CONTEXT.md`: Bullet, Folder Bullet, Outline File, Root Outline, Annotation, Bullet ID, Orphan, Broken Folder Bullet, Admin, Skill.

### Task 3: core — annotation tokenizer

**Files:** `packages/core/src/annotations.ts`, tests.

**Produces:**
```ts
type Segment = { kind: "text"; text: string } | { kind: "annotation"; kinds: string[]; value: string | null; raw: string };
parseSegments(line: string): Segment[]
serializeSegments(segs: Segment[]): string
const METADATA_KINDS = ["id","folder","date","priority","done"] as const;
const STYLE_KINDS = ["bold","italic","highlight","code","red","green","blue","yellow","purple","grey"] as const;
splitMetadata(line: string): { text: string; meta: Record<string,string|true> }   // text keeps inline annotations, meta holds metadata kinds
joinMetadata(text: string, meta: Record<string,string|true|undefined>): string      // appends in canonical order
```
Rules: `\[` and `\]` escapes; `[a,b:value]` → kinds `["a","b"]`; `[done]` → value `null`; unknown kinds are kept as-is (text passthrough as annotation with unknown kind); unterminated `[` is literal text.

- [ ] Tests: `parseSegments("hi [bold:there] x")` → 3 segments; combined kinds; flag form; escapes round-trip through `serializeSegments`; `splitMetadata("Fix login [id:abc12345] mid [date:2027-09-15]")` → text `"Fix login mid"`, meta `{id:"abc12345",date:"2027-09-15"}`; `joinMetadata("Fix",{done:"2026-09-19",id:"abc12345"})` → `"Fix [id:abc12345] [done:2026-09-19]"`; unterminated bracket preserved.
- [ ] Implement; run; commit `feat(core): annotation tokenizer and metadata split/join`.

### Task 7: core — three-way merge by id

**Files:** `packages/core/src/merge.ts`, tests.

**Produces:** `mergeOutlines(base: OutlineFile, mine: OutlineFile, theirs: OutlineFile): OutlineFile`. Algorithm: flatten each to `Map<id, {bullet without children, parentId, index}>`. For each id: if changed only in mine → mine; only in theirs → theirs; both → theirs. Structure: start from `theirs` tree; add Bullets present only in mine (new in mine) under the same parent id at their index (append if parent gone → append to root). Remove Bullets deleted in mine that are unchanged in theirs. Header from theirs.

- [ ] Tests: disjoint edits both survive; mine adds child, theirs edits sibling → both; same-bullet conflict → theirs; mine deletes, theirs untouched → deleted; theirs deletes, mine edits → theirs (deleted).
- [ ] Implement; run; commit `feat(core): three-way merge by bullet id`.

### Task 10: server — store

**Files:** `packages/server/package.json` (`@lister/server`, deps `fastify`, `@fastify/websocket`, `@fastify/static`, `chokidar`, `@lister/core: workspace:*`), `packages/server/src/config.ts`, `packages/server/src/store.ts`, tests.

**Produces:**
```ts
loadConfig(home = os.homedir()): Config  // { rootFile, port, recentFolders, listerDir }
class Store {
  constructor(cfg: Config, opts?: { onChange?: (path: string) => void })
  async root(): Promise<OutlineFile>
  async file(path: string): Promise<OutlineFile>             // loads, heals, caches, starts watching
  async locate(id: string): Promise<{ file: OutlineFile; bullet: Bullet } | null>  // searches loaded files, then walks unloaded Folder Bullets from root
  async addBullet(filePath, parentId|null, index, text): Promise<Bullet>
  async patchBullet(id, patch): Promise<Bullet>              // renaming a Folder Bullet renames its file
  async moveBullet(id, filePath, parentId|null, index): Promise<void>
  async deleteBullet(id): Promise<void>                       // Folder Bullet: detach only
  async toFolder(id, folder): Promise<Bullet>                 // refuses if slug file exists
  async inline(id): Promise<Bullet>
  async flush(): Promise<void>                                // await pending debounced writes
  async externalChange(path): Promise<void>                   // read disk, merge, write if healed, emit onChange
  close()
}
```
Writes: debounce 150 ms per file; keep `lastWritten` text per path for merge base; ignore watcher events whose content equals `lastWritten`.

- [ ] Tests use a temp home dir. Cases: root created on first access with header; add/patch/move/delete persist to disk after `flush()`; `toFolder` creates `<dir>/<slug>.lister` with header `[parent:]` and moves children, parent line gains `[folder:]`; `toFolder` collision throws; `inline` reverses; external edit adding a line merges with an in-memory unflushed edit to another Bullet.
- [ ] Implement; commit `feat(server): file store with debounced writes and merge`.
